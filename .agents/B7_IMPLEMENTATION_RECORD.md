## Corrections made while translating the owner proposal

1. Collision redistribution is described only as discount-equivalent from the
   beginning of the one-second window and earlier, not at every state inside
   the window.
2. The current-rollout safe cap is explicitly scoped to observation histories
   generated by the pre-update policy. It does not claim to constrain the
   candidate's next closed-loop state distribution.
3. Old-policy rollout KL is the exact nonnegative fixed-variance Gaussian
   mean-KL; raw-action PPO ratios still use stored old/new log-probability.
4. Full recurrent replay is frame-by-frame from zero hidden. A fused GRU call
   is not used because it can differ numerically from the evaluator's batch-one
   execution.
5. The 288 panel's directional cluster is L4, not Austin startpoint. The exact
   one-sided sign-flip tail is computed by dynamic programming.
6. The absolute `collision<=18` and paired `fixed-new>=6` checks are retained
   for reporting but explicitly marked algebraically redundant at BC=24.
7. Hard mining is frozen to the immediately preceding iteration; missing slots
   use hash-selected BC-overtake preservation rows. This avoids a stale
   candidate-outcome cache while keeping every current rollout on-policy.
8. Seed0 CLI execution fails closed without a passed B7 seed1 288 summary.
