# B5-A post-hoc statistical qualification

This directory is generated by `scripts/analyze_b5_statistical_noise.py` from
the immutable B5-A 2,400 paired rows. It is a read-only qualification of an
already-open development panel, not a new experiment or confirmation result.

- `paired_inference.tsv`: occurrence McNemar, startpoint sign-flip, and
  startpoint bootstrap results by snapshot and metric.
- `startpoint_effects.tsv`: the 50 block-level net effects used by the clustered
  calculations.
- `summary.json`: input identity, joint snapshot-selection result, assumptions,
  and claim boundary.
