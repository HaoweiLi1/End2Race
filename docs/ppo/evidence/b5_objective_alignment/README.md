# B5-A objective-alignment mechanism audit

This directory is generated by `scripts/analyze_b5_objective_alignment.py`.
The remote RTX 4080 SUPER run is read-only: it replays frozen B4/B5 artifacts
and executes counterfactual actor epochs in memory; it does not create a
learner checkpoint or evaluate a candidate.

- `function_updates.tsv`: actual B5 checkpoint increments on four fixed
  function probes.
- `gradient_alignment.tsv`: full-rollout negative loss-gradient decomposition
  by archived BC outcome and probe.
- `candidate_epoch_alignment.tsv`: restored actor+Adam base-epoch
  counterfactuals for original and opened-Austin weights.
- `gradient_iteration_summary.tsv`: compact comparison across iterations 1-10.
- `summary.json`: artifact inventory, validation, aggregate result, and claim
  boundary.
- `remote_run.log`: unedited stdout from the bound remote analysis run.
